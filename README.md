# Atria

## Demo de casa por voz

Con ATRIA activo en FreeCAD, decí **«Activar demo casa»** y después **«Ayuda casa»** o **«Ayuda habitaciones»**. Los carteles permiten dictar medidas y elegir nombres, habitaciones, paredes, pisos y piezas. Para una medida, dictá el valor y decí **«Aceptar»**. Para una opción, decí el nombre o recorré las opciones con **«Arriba»** y **«Abajo»** y confirmá.

**«Guardar casa»** guarda el modelo en `ATRIA/outputs` dentro de tu carpeta de usuario. **«Salir de la demo casa»** vuelve al vocabulario habitual de ATRIA.
